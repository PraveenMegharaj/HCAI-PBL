Project 4 · Preference Elicitation for Movie Recommendation

A user-study interface comparing two ways to elicit a new user's movie preferences: pairwise choices vs. ranking a set of ten. Built on the IMDB 5000 dataset with a Plackett-Luce preference model.

Report

PDF report covering the feature representation (Task 1), the Plackett-Luce extension of Bradley-Terry (Task 2), the design of the user study (Task 3), and the interface (Task 4).

Take part in the study

The whole thing takes about 5–10 minutes. Your responses are stored anonymously — no personal identifiers are collected. Each participant is randomly assigned to one of two interface conditions.

Start the user study →

What you'll do

You will be randomly assigned to one of two conditions:

  • Design 1 · Pairwise choice. You are shown two movies at a time and click the one you'd rather watch. Repeated {{ n_trials_pairwise }} times.
  • Design 2 · Rank a set. You are shown a set of {{ ranking_set_size }} movies and drag them into your preferred order (best on top, worst at the bottom). Repeated {{ n_trials_ranking }} times.

Both designs elicit the same underlying preference vector — the point of the study is to compare their ergonomics and data quality.

Software structure

Code is split into ml.py (dataset loading, feature extraction, Plackett-Luce), models.py (Participant, PairwiseResponse, RankingResponse), forms.py, urls.py, views.py (thin controllers), and tests.py. All responses are visible in /admin for the researcher.
